  Open a terminal in the project root and run:

    cd pharma-frontend
    npm run test:jest                  ← run all tests (with pass/fail summary)
    npm run test:jest:coverage         ← run all tests + show coverage %

  That's it. No browser, no server, no Angular CLI needed.

  HOW TO ADD A NEW TEST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Create a file next to the class you want to test:
       src/app/services/my-service.spec.ts

  2. Write your test using Jest syntax:

       import { MyService } from './my-service';

       const mockHttp = { get: jest.fn(), post: jest.fn() } as any;

       describe('MyService', () => {
         let service: MyService;

         beforeEach(() => {
           jest.clearAllMocks();
           service = new MyService(mockHttp);
         });

         it('does something', () => {
           mockHttp.get.mockReturnValue(of([]));
           service.getAll().subscribe(result => {
             expect(result).toEqual([]);
           });
         });
       });

  3. Run:  npm run test:jest

  Jest automatically finds all *.spec.ts files — no registration needed.

  HOW IT WORKS (TECHNICAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Angular 21 ships as ESM-only (.mjs) packages which Jest cannot parse
  natively. Instead of loading the full Angular runtime, we use lightweight
  stubs in src/__mocks__/@angular/ that replace Angular's decorators,
  dependency injection, and signals with simple JavaScript equivalents.

  This means:
    • Tests run in milliseconds (no browser, no zone.js, no compilation)
    • Dependencies are injected manually via constructor arguments
    • HTTP calls are mocked with jest.fn() — no real network requests
    • localStorage is provided by jsdom (the test environment)

  The stubs implement just enough of the Angular API for the business logic
  to work:
    • signal(value)     → simple getter/setter wrapper
    • computed(fn)      → returns the function itself (call it to get value)
    • inject(token)     → returns undefined (tests override deps manually)
    • Injectable/Component/Input → no-op decorators
